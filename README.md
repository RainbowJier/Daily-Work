# Daily-Work

日常工作管理仓库，用于按周整理和保存工作记录。

## 目录结构

工作记录按「年 / 月 / 周」分层存放：

```text
Task/ (仓库根)
└── 2026/
    └── 08/
        └── 08-10~08-16/
            └── 工作记录.md
```

- 按 ISO 周划分（周一至周日），每周一个 `工作记录.md`。
- 跨月的周按周一所在月份归入对应月文件夹。

## 记录格式

每个 md 文档按天分节（`## MM-DD 周X`），条目按时间顺序排列，支持按分组独立编号（如「门户四中心 / 公司 / 个人」）。

条目状态四种：

| 状态 | 含义 |
| --- | --- |
| `[ ]` | 待办（未开始） |
| `🎯` | 正在执行中（进度写在括号里） |
| `✅` | 已完成（绿色，括号内注明完成日期） |
| `[-]` | 已取消（括号内注明原因） |

## 使用方式

- 每周工作内容发送后整理成条目写入本周文档；
- 报告完成情况时把对应条目标为 `✅` 并注明日期；
- 每次修改后更新文档顶部的 `> 更新：` 日期。
